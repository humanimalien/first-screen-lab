# Проверка версии 1.0.0

Проверено 15 ноября 2026 года на Node.js 24.15.0 и Wrangler 4.50.0.

- Чистая копия без `node_modules`, `.dev.vars` и локальной базы: `npm ci` установил 55 пакетов по lock-файлу.
- `npm run check`: настройки корректны.
- `npm test`: пять тестов пройдены. Проверены повтор регистрации после потери ответа, личные ссылки, отдельный новый профиль, все 12 этапов, таймеры и прерывание показа, повтор сохранения без двойных баллов, подписанные ответы, решения автора, архив после перезапуска, удаление и восстановление вариантов, права преподавателя, произвольное число групп и проверка конфигурации.
- `npm run deploy:check`: сборка Wrangler успешна; 1757 КиБ до сжатия, около 768 КиБ gzip.
- `npm run db:local`: начальная миграция применена в локальном D1, 14 SQL-команд.
- Локальный Worker запущен через `npm run dev`: главная, конфигурация, JavaScript, Inter и учебная картинка возвращают 200. Вымышленный участник вошёл без пароля, получил подписанную личную ссылку, загрузил PNG, затем тот же файл прочитан из локального R2; запись о версии прочитана из D1.

Проверен и `npm run recover` на локальной D1: несуществующий ID отвергается, старая ссылка и сессии отзываются, новая ссылка открывает тот же профиль.

Облачная публикация на аккаунте другого преподавателя не выполнялась: свои ID ресурсов, секреты и права GitHub Actions задаёт владелец новой установки. Полный контроль перед занятием — в `INSTALL-CHECK.md`.

Локальные базы, сессии, случайные секреты и `node_modules` в архив не входят. Это пакет для новой пустой установки; миграция действующей Sites-базы не выполняется.

# Контрольный проход перед занятием

Проверьте сначала локальную установку, затем свой опубликованный адрес. Используйте вымышленных участников и разные профили браузера для автора и проверяющего: обычные вкладки одного профиля используют общую сессию. В поставке оставлены три вымышленных студента для такой пробы. Для реального потока настройте список до первого входа.

1. Главная открывается без ChatGPT и пароля. Группы и имена соответствуют `workshop.config.json`. Ссылка на пример ведёт туда, куда вы указали.
2. Войдите как студент. Скопируйте личную ссылку в шапке, выйдите и откройте её. Вы вернулись в тот же профиль.
3. В «Моём экране» загрузите JPG или PNG. Он виден в истории, исходная загрузка даёт ноль баллов.
4. В «Маршруте» откройте первый этап, заполните подготовку и опубликуйте испытание. В другом профиле браузера войдите как одногруппник: этап доступен для проверки, авторская подготовка заранее ему не показывается.
5. Сохраните ответы одногруппника. Автор видит имя и ответы; рейтинг проверяющего вырос на число отвеченных вопросов.
6. Автор фиксирует правку с объяснением: получает три балла. При выборе «оставить» объяснение обязательно.
7. В свободной проверке нажмите плитку и «Начать показ». Экран исчезает через пять секунд. Уход со вкладки прерывает показ; повтор сохраняет ответы уже пройденных частей маршрута.
8. Студент не может получить полномасштабное чужое изображение через ссылку преподавательского просмотра. При выборе преподавателя без правильного ключа вход запрещён; с ключом открывается обзор всех эскизов.
9. «Начать маршрут заново»: загрузите другой экран. Текущим становится первый этап новой попытки, прежние ответы и решения остаются в архиве, баллы за свой экран прежней попытки равны нулю. Баллы проверяющего за ответы сохраняются.
10. Удалите свой вариант из галереи и восстановите его. Удаление не стирает историю испытаний.
11. Перезапустите локальный сервер или обновите облачный код. Работы, вход и история сохранились.

Автотесты `npm test` дополнительно проходят все 12 этапов с временной SQLite-базой, включая таймеры, повтор сохранения, подписанные ответы, архив попыток, пересчёт баллов и преподавательский доступ. `npm run deploy:check` проверяет сборку Wrangler без облачной публикации.

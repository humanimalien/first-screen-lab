# Устройство пакета

| Файл или папка | Назначение |
| --- | --- |
| `workshop.config.json` | Названия, участники и преподаватели вашей установки |
| `index.html`, `app.js`, `style.css` | Интерфейс и пятисекундный показ |
| `access-store.js` | Сохранение личной ссылки и безопасный повтор регистрации в браузере |
| `stages.js` | 12 этапов, авторские вопросы и вопросы проверяющему |
| `worker/index.js` | Сессии, вход, версии, загрузка изображений, рейтинг и права |
| `worker/rounds.js` | Маршрут, ответы, решения, архив попыток |
| `worker/thumbnails.js` | Небольшие растровые превью для студентов |
| `migrations/0001_initial.sql` | Пустая итоговая схема D1 |
| `scripts/build.mjs` | Сборка Worker с локальными интерфейсными файлами и конфигурацией |
| `wrangler.json` | Привязки к собственной D1 и R2 |
| `.github/workflows` | Проверки и ручная публикация через GitHub Actions |
| `tests` | Автотесты на вымышленных профилях и временной SQLite-базе |

Worker выдаёт и интерфейс, и `/api`; отдельный frontend-хостинг и настройка CORS не требуются. Сборка включает Inter и учебную картинку локально. Единственная внешняя учебная зависимость — необязательная ссылка на референс; приложение не читает исходный сайт студентов и не обращается к нему за списком имён.

D1 хранит `members`, `sessions`, `versions`, `attempts`, `self_tests`, `rounds`, `round_runs`, `route_restarts`. Изображения хранятся в R2 по ключам из базы. Паролей студентов нет; сессия — случайный секрет в HttpOnly/Secure cookie, личная ссылка подписана HMAC серверным секретом. Ключи в ссылках находятся после `#` и удаляются из адреса после успешного входа.

Преподаватель определяется по неизменному ID из `teachers`, его первый вход требует секрет TEACHER_ACCESS_KEY. Студент не получает преподавательские права при выборе такого имени без ключа. Отсутствие университетской проверки личности у первой студенческой регистрации — сознательное ограничение этой версии.

Для переноса на VPS потребуется адаптер D1 (`prepare/bind/first/all/run` и атомарный `batch`) поверх SQLite/PostgreSQL и адаптер R2 (`get/put/delete`) поверх закрытого файлового или S3-хранилища. Этот пакет проверяется для Cloudflare Workers; готового VPS/Docker-адаптера в нём нет.

Практика создана для учебного разбора первого экрана. Пять секунд задают одинаковое ограничение показа; они не доказывают ни конверсию, ни спрос. Вопросы и баллы позволяют собрать материал для обсуждения, качество объяснения оценивается при разборе преподавателем.
